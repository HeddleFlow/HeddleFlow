# Contributing to HeddleFlow

HeddleFlow works with AI agents to build a new product from an idea, or grow an existing one from a change, through
to release.

## How HeddleFlow is developed

**HeddleFlow is open source, but not open development.** It is built in a private repository by its maintainers, and
each release is published here, in this repository, under the Apache License 2.0. Everything a project receives is in
the release, readable by anyone, and yours to use, study and change under that licence.

**This repository does not take pull requests.** Its code is published from the private repository, so a change made
here would be overwritten by the next release. Contributions of code may open later; this page will say so when they
do.

## What you can do

**Report a bug, or suggest an improvement, as an issue.** Every issue is read, and each one is answered on the issue
itself. A fix or an improvement arrives in a release, and the issue is closed with a reply saying which.

- **A bug**: open an issue with the *Report a bug* form. It asks for:
  - what happened, with any message HeddleFlow printed;
  - what you expected;
  - the harness, the surface and the OS you ran it on;
  - HeddleFlow's version, as `uv run .heddleflow/hdf.py version` prints it in your project;
  - the steps to reproduce it, from a fresh project.
- **A suggestion**: open an issue that says what you are trying to do, what gets in the way today, and what would help.
  A suggestion about the help goes here too.
- **A security problem**: never in a public issue. Report it privately, as [`SECURITY.md`](SECURITY.md) says.
